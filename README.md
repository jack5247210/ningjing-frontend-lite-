寧境芳療系統 – 前端
Angular 19 前端應用，包含會員登入、線上預約、電商購物、後台管理等完整功能模組。

技術棧
Angular 19

TypeScript

RxJS

Bootstrap 5

RWD 響應式設計

功能特色
JWT 身分驗證與權限控管

Google OAuth2 第三方登入

線上預約（自動排除公休日、即時查詢名額）

購物車與訂單管理

後台管理介面

安裝與執行
bash
npm install
ng serve
後端 API 來源
此專案搭配的後端 API 為：https://github.com/jack5247210/ningjing-spa-backend
